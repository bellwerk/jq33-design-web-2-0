How it works

How the process works

Four clear steps from first call to a contractor-ready design package for your commercial space in Montreal.

01

Introductory call

We align on goals, timeline, budget, and constraints, so the design is decisive from day one.

02

Measurements + photos

You share measurements, a floor plan (if available), and photos/video. A site measure can be coordinated in Montreal if needed.

03

Layout + concept + 3D

You receive a space plan, finishes direction, and 3D visuals for key customer viewpoints, then we refine with revisions.

04

Contractor-ready next steps

A clean package you can share for quoting, so what gets built matches what you approved.

FAQ

QUOTE
INPUTS

What do you need to quote?

Space type, Montreal-area location, approximate square footage, timeline, budget range, and any existing floor plan or lease constraints.

PERMITS
+ STAMPS

Do you do permits and stamped drawings?

We provide a contractor-friendly design package (layout + finishes + lighting intent + visuals). If your project needs permit-ready drawings or stamps, I can coordinate with an architect, technologist, or engineer depending on scope.

CONTRACTOR
WORKFLOW

Can you work with my contractor?

Yes. We can hand off a clean package for quoting and stay available during the build so the result stays consistent.

STYLE
CLARITY

I'm not sure about my style yet—is that a problem?

Not a problem. We use references, moodboard, finishes direction, and visuals to create clarity quickly before money is spent.
